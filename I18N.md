## Introduction

Now the i18n system of day.dart contains the following keys:

- Months
- MonthsShort
- MonthsFormat (optional)
- MonthsShortFormat (optional)
- Weekdays
- WeekdaysShort
- WeekdaysMin
- AM
- PM
- RelativeTime

For example, let’s take a look at [i18n/en.dart](https://github.com/dayjs/day.dart/blob/master/lib/i18n/en.dart):

```dart
final Map<String, dynamic> locale = {
  'Name': 'en',
  'Months': {
    1: 'January',
    2: 'February',
    3: 'March',
    4: 'April',
    5: 'May',
    6: 'June',
    7: 'July',
    8: 'August',
    9: 'September',
    10: 'October',
    11: 'November',
    12: 'December'
  },
  'Weekdays': {
    1: 'Monday',
    2: 'Tuesday',
    3: 'Wednesday',
    4: 'Thursday',
    5: 'Friday',
    6: 'Saturday',
    7: 'Sunday'
  },
  'AM': 'AM',
  'PM': 'PM',
  'RelativeTime': {
    'future': 'in %s',
    'past': '%s ago',
    's': 'a few seconds',
    'm': 'a minute',
    'mm': '%d minutes',
    'h': 'an hour',
    'hh': '%d hours',
    'd': 'a day',
    'dd': '%d days',
    'M': 'a month',
    'MM': '%d months',
    'y': 'a year',
    'yy': '%d years'
  }
};
```

You may have noticed many keys like `Months` and `Weekdays`, but where are the remaining keys such as `MonthsShort` mentioned above?

Because `MonthsShort` is just a substring of the full month name in English. For example, the `MonthsShort` of `January` is `Jan`, taken from characters 0 to 3.

`WeekdaysShort` is taken from characters 0 to 3.

`WeekdaysMin` is taken from characters 0 to 2.

However, in different languages, the **short** forms of months and weekdays are not the same as in English.

You can view other locale files like [i18n/zh_cn.dart](https://github.com/dayjs/day.dart/blob/master/lib/i18n/zh_cn.dart) for more details.

### Month forms in dates

Locales can provide optional `MonthsFormat` and `MonthsShortFormat` maps,
indexed from 1 to 12. These forms are used for `MMMM` and `MMM` when the
month token immediately follows `D` or `DD`, separated by whitespace or
bracketed literal text. Otherwise, `Months` and `MonthsShort` are used.
Locales without these optional maps keep their existing behavior.

These two optional maps are currently used only for Russian month forms.

For example, Russian `MMMM` displays `апрель`, while `D MMMM YYYY` displays
`30 апреля 2019`. `D [day] MMMM` also uses the date form; `[D] MMMM` does not,
because the day token is escaped.

### Relative time forms

With the relative time plugin, unit entries in `RelativeTime` can be strings
or callbacks with the signature `String Function(int count, bool withoutSuffix)`.
The callback returns a template; `%d` is replaced with the absolute count.
`withoutSuffix` is true when the optional boolean argument to `from`, `to`,
`fromNow`, or `toNow` is true. The `future` and `past` entries remain strings
containing `%s`.

For example, Russian uses `минута` without a suffix, but `минуту` in
`через минуту` and `минуту назад`. German similarly uses `eine Minute` on
its own and `einer Minute` in `in einer Minute` or `vor einer Minute`.

## How To Use

For global usage:

```dart
import 'package:day/day.dart';
import 'package:day/i18n/zh_cn.dart' as zh_cn_locale;

void main() {
  Day.locale = zh_cn_locale.locale;

  final d = Day.fromString('2019-04-30T10:30:30.000Z');
}
```

For local usage:

```dart
import 'package:day/day.dart';
import 'package:day/i18n/zh_cn.dart' as zh_cn_locale;

void main() {
  final d =
      Day.fromString('2019-04-30T10:30:30.000Z').useLocale(zh_cn_locale.locale);
}
```

Local usage takes priority over global usage.

## Locale data conventions

Locale data follows [Unicode CLDR](https://cldr.unicode.org/translation/date-time/date-time-names)
conventions for each language and region, including spelling, capitalization,
abbreviation punctuation, and spacing.

Relative times use natural expressions such as "a few seconds" and "a minute".
Existing localized expressions are retained where CLDR does not provide a
translation.
